# GMV Max ROI Calculator — Online

Web app untuk menghitung ekonomi target ROI TikTok Shop / GMV Max.

## Deploy cepat ke Vercel
1. Upload folder ini ke GitHub.
2. Import repository di Vercel.
3. Deploy dengan framework preset `Other` (atau biarkan auto-detect).
4. Buka URL Vercel dari HP.

### Penting
Scanner hanya dapat membaca data yang tersedia dari halaman publik. HPP, fee Seller Center, affiliate, voucher, histori spend, GMV, dan ROI campaign tetap perlu dimasukkan dari akun Seller Center. TikTok dapat mengubah struktur halaman atau memblokir automated requests, sehingga hasil scan publik tidak dijamin selalu tersedia.
